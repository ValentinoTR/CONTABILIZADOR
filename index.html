Seguridad de datos

Esta app usa una publishable key de Supabase en el frontend, lo cual está bien siempre que las tablas COMPRAS y COMPONENTES tengan Row Level Security (RLS) activado con políticas que solo permitan leer/escribir a usuarios autenticados (o al dueño de los datos). La protección real de tus números depende de esas políticas en Supabase, no de que el formulario esté oculto antes de iniciar sesión — revisa esto directamente en el panel de Supabase → Authentication/Table Editor → Policies.
